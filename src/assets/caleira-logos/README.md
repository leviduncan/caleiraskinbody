# CALÉIRA Skin & Body: Logo Kit (v1, proposed)

All text is converted to outlines, so every SVG renders correctly anywhere with no fonts installed.
Wordmark: Bodoni Moda 700 (small-size cut, opsz 11). Sub-line and tagline: Jost. Monogram: arch with a knocked-out Bodoni C.

## Which folder to use
| Folder | Use it on | Colors |
| --- | --- | --- |
| svg/light | Coquina ivory, white, light photos | mahogany #5A2A1B + champagne #C8A675 hairlines |
| svg/dark | Evening cocoa, dark photos | ivory #F3EADF + champagne #D8B887 hairlines |
| svg/mono-mahogany | One-color print, stamps, embroidery on light | mahogany only |
| svg/mono-ivory | One-color on dark or photos | ivory only |
| svg/shared | Skin-tone band (always all six tones, equal weight) | tone-1 to tone-6 |

All logo files have transparent backgrounds. Icons (square, with ground) are the exception: use them for favicon, Instagram, Google Business Profile and app tiles.

## Files
- lockup-tagline: arch, wordmark, SKIN & BODY, "Designed to Be Noticed." (hero, print, signage)
- lockup-stacked: arch, wordmark, SKIN & BODY (default)
- lockup-horizontal: arch left, wordmark right (website header, email signature)
- wordmark: CALÉIRA only (tight spaces)
- monogram: arch C only (social avatar, stamp, packaging seal)
- icon / icon-rounded: square tile with ground color

## Rules
- Do not recolor outside the four sets above. No gradients, no foil, no drop shadows.
- Keep clear space around any logo equal to the width of the C in the monogram.
- Minimum size: stacked and horizontal lockups 120 px wide on screen. Below that, use the monogram or wordmark.
- Never use pure black.
- PNG exports are in png/ (transparent, 2400 px wide). Favicons in png/favicon.
